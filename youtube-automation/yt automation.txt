# YouTube Shorts Automation Pipeline — Complete Documentation

## Project Overview

Yeh ek fully automated YouTube Shorts pipeline hai jo:
1. RSS feed se latest news article uthata hai
2. Claude AI se punchy script banata hai
3. edge-tts se voiceover generate karta hai
4. Pexels se stock video clips download karta hai
5. moviepy se sab merge karta hai + PIL se captions burn karta hai
6. YouTube pe automatically upload karta hai

Trigger: n8n se — har 6 ghante scheduled, ya on-demand webhook se.

---

## System Architecture

```
n8n (localhost:5678)
  ├── Schedule Trigger (har 6 ghante)
  └── Webhook Trigger (on-demand)
        ↓
    Merge Node
        ↓
    HTTP Request Node
        ↓
ngrok (public URL → localhost:8000)
        ↓
FastAPI Server (localhost:8000) — server.py
        ↓
    run_all.py
      ├── pipeline.py  (Phase 1-3: RSS + Script + Audio + Video)
      └── merge_fixed.py  (Phase 4: Merge + Captions)
      └── upload.py  (Phase 5: YouTube Upload)
        ↓
    final_short.mp4 → YouTube Shorts ✅
```

## Pipeline Phases Detail

### Phase 1 — RSS → Claude Script
**File:** `pipeline.py`
- `feedparser` se RSS_URL parse karta hai
- Latest article ka title + summary extract karta hai
- Claude API ko prompt bhejta hai
- Output: 8-line JSON script with keywords per line

**Claude Prompt Logic:**
- Line 1: Strong hook
- Lines 2-7: Key points
- Line 8: Call to action
- Per line: 1-3 keywords for Pexels search

### Phase 2 — Script → Audio
**File:** `pipeline.py`
- `edge-tts` se har line ki MP3 generate karta hai
- Voice: en-US-AriaNeural
- Output: `line_01.mp3` to `line_08.mp3`

### Phase 3 — Keywords → Video Clips
**File:** `pipeline.py`
- Pexels API se har line ke keywords ke liye portrait video search
- Fallback queries: agar specific keyword fail ho toh generic try karta hai
- `random.choice` se same clip repeat nahi hota
- Output: `clip_01.mp4` to `clip_08.mp4`

### Phase 4 — Merge + Captions
**File:** `merge_fixed.py`
- Latest run folder dhundta hai
- Har line ke liye: audio duration nikaalta hai, video clip crop karta hai (9:16 portrait), loop karta hai agar video choti ho
- PIL se caption image banata hai (rounded dark background, white text, shadow)
- moviepy se sab concatenate karta hai
- Output: `final_short.mp4` (30-35 seconds)

**Caption Style:**
- Font size: 52px, Arial
- Color: White with black shadow
- Background: Semi-transparent rounded rectangle (rgba 0,0,0,160)
- Position: Center of screen

### Phase 5 — YouTube Upload
**File:** `upload.py`
- `token.json` se credentials load karta hai (ya first time OAuth flow)
- `privacyStatus: private` pe upload karta hai (check ke baad public karo)
- Title: Claude ka generated title
- Description: Article title + hashtags
- Category: News & Politics (25)
- Output: Video ID + YouTube URL

## Known Issues & Solutions

| Issue | Cause | Solution |
|---|---|---|
| ngrok URL changes on restart | Free ngrok plan | Update HTTP Request node URL manually |
| Pexels sirf 3-5 clips milti hain | Keywords too specific | Fallback queries already implemented |
| n8n Execute Command nahi hai | Cloud/newer n8n versions | FastAPI server use kiya |
| TextClip captions nahi dikhte | moviepy 2.x font issue | PIL se captions banaye |
| Windows Defender ngrok block karta hai | Tunneling tool | Microsoft Store wala ngrok use karo |
| YouTube upload Access Blocked | OAuth test user nahi tha | Google Cloud Console mein email add karo |
